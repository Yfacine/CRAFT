# REAP

REA에 전달할 조사 질문을 고르는 커뮤니티 프롬프트 모음이다. 프로젝트 사본은 `.tools/reap/README.md`에 있다. 기능 복제, 파일 호환, 행동 동등성 등 필요한 절을 먼저 찾는다.

1. 기능 ID 하나와 원본 경로·버전, 조사 허용 범위를 정한다.
2. 트리거, 정상·경계 입력, 출력과 상태 변경, 실패 시 동작을 요청한다. 필요한 근거는 대상에 맞게 화면, 실측 로그, 파일, 함수·주소 중에서 고른다.
3. 적용한 프롬프트 절과 실제로 사용한 질문을 대상 기록에 남겨 REA 조사와 연결한다.
