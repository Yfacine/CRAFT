# CRAFT 도구 레퍼런스

각 레퍼런스에 연결된 고정 배포·리비전과 `.tools` 사본을 사용한다. 대상별로 실제 실행 버전과 산출물을 기록하고, 도구 가이드는 배정된 역할과 허용 범위에 맞게 적용한다.

### 갱신 기록 방법

1. 공식 배포 또는 기본 브랜치, 런타임 호환 조건과 입출력 변경을 확인한다.
2. 새 도구를 가져올 때 **실제 가져온 날짜·버전 또는 전체 커밋·로컬 위치**를 새 행에 적고 이전 행을 보존한다. 최신 버전 조회만 한 경우 기존 가져온 날짜를 유지한다.
3. 버전과 작은 읽기 사례를 검증한 뒤 사용 경로를 전환한다. REA나 Node 버전을 바꾸면 [초기화 스크립트](../../scripts/Initialize-Craft.ps1)의 도구 경로도 함께 갱신한다. 새 행을 `사용 중`, 교체된 행을 `이전`으로 표시하고 [작업공간 검증](../03_verification.md)에 전환 근거를 남긴다.
