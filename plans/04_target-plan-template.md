# CRAFT 대상계획 양식

MAIN은 이 양식을 `plans/targets/<대상-id>.md`로 복사해 대상별로 작성한다. 작업 순서와 인수 기준은 [공통 운영계획](01_main-plan.md#4-인계와-검증-순서)을 적용한다. 표의 `F01 / AC01 / O01`은 연결 형식을 보여 주는 예시이며 대상의 실제 ID로 교체한다. 복사본에서는 메인 계획서와 Gate 문서의 상대 링크에 각각 `../`를 붙인다.

## 4 후보와 실행 증거

### 4.1 후보 식별과 독립 검토

현재 적용 후보 ID를 지정한다. 후보를 교체하거나 동일 후보의 기준을 변경할 때는 기존 행을 보존하고 새 후보·기준 조합을 추가한다.

| 후보 ID | 코드 리비전·파일 지문 | 해당 배포물 경로·지문 | 명세·인수 기준·테스트 버전 | 독립 검토·후보 정합성 근거 및 미해결 결함 |
| --- | --- | --- | --- | --- |
| | | | | |

독립 검토 근거에는 적용 후보와 기준을 연결한다. 후보 정합성에는 구현 위치와 검증 결과를 연결한다.

### 4.2 실측 결과

환경과 초기 상태, 입력 지문, 재현 명령, 실행 일시와 담당을 실행 기록에 남긴다. 각 행은 실행한 배포물·기준 버전·실행 조건에 연결한다. 재실측은 새 행으로 남기고 이전 결과를 보존한다.

| 기능 ID | 인수 사례 ID | 필수 관찰 항목 ID | 후보·실제 배포물 지문 | 기준 버전·실행 조건 기록 | 실제 결과·증거 위치 | 판정 |
| --- | --- | --- | --- | --- | --- | --- |
| F01 | AC01 | O01 | | | | NOT RUN |
